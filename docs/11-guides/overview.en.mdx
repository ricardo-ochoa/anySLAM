## How the search works

The search understands synonyms, so you do not need to know the command's name:

| If you type… | You get |
| --- | --- |
| `delete` | Everything that removes something: `rm`, `rmi`, `prune`, `down`. |
| `delete volume` | Only what removes volumes: `docker volume rm`, `docker volume prune`. |
| `enter` | `docker exec -it`, `docker attach`, `docker compose exec`. |
| `undo commit` | `git reset --soft`, `git commit --amend`, `git revert`. |

Words stack: every one of them has to match. Commands with a red mark on the left delete things.
