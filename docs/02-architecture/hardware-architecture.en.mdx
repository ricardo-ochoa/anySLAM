## Platform

The project robot is an **ANYmal D** by ANYbotics: a research quadruped with twelve actuated
joints (three per leg: HAA, HFE and KFE) and series-elastic actuators.

What is confirmed about the team's use of it comes from the
[`Anymal-Research`](https://github.com/jesusMBhuy/Anymal-Research) repository, which trains
against the official ANYmal D USD model shipped with Isaac Lab:

```
Assets/Isaac/5.0/Isaac/IsaacLab/Robots/ANYbotics/ANYmal_D/anymal_d.usd
```

This confirms the variant (**D**) and that the dynamic model used in simulation is the
manufacturer's, including LSTM-based actuator modelling.

## Navigation experiment sensors

The [ICRA 2025 poster](/en/docs/09-research/papers) documents the hardware of a **different**
experiment, on a shuttle:

| Component | Model | Purpose |
| --- | --- | --- |
| Platform | Shuttle Personnel Carrier EG6088K | Test vehicle |
| 3D LiDAR | Velodyne HDL-32 | Sparse point cloud |
| Camera | MultiSense S21 | Stereo RGB imagery |

Do not assume this is the ANYmal's hardware. It is documented here because it is the only sensor
setup for which we have a written source.

## Training compute

Requirements declared in the `Anymal-Research` README for the training machine:

| Resource | Requirement |
| --- | --- |
| GPU | NVIDIA with CUDA (RTX series recommended) |
| RAM | 16 GB minimum, 32 GB recommended |
| Storage | 50 GB or more |
| CPU | 8 cores or more |
