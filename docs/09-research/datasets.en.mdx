## External datasets

### SCAND — Socially Compliant Navigation Dataset

A navigation dataset with human demonstrations across diverse scenarios. The team uses it to
train the navigation architecture, aiming for robustness across different human navigation
behaviours.

**Reference:** Karnan et al. (2022), [arXiv:2203.15041](https://arxiv.org/abs/2203.15041)

### PushT

A manipulation environment used as an initial test bench, from the Diffusion Policy work (Chi et
al., 2023). It is not a project dataset but a validation environment.

What we need to know:

| Question | Why it matters |
| --- | --- |
| What is recorded during experiments? | Determines what analysis is possible afterwards |
| In what format? (rosbag, HDF5, other) | Defines which tools are needed to read it |
| Where is it stored, and how large is it? | Determines whether a new member can access it |
| What preprocessing is applied? | Needed to reproduce any training run |
| How is it versioned? | Without this, past results cannot be reproduced |
| Is there personal data or usage restriction? | Legal and ethical obligations |
