Elige la ruta que corresponda a tu trabajo. No instales lo que no vayas a usar: la pila de
simulación es pesada y no la necesitas para documentar ni para trabajar en ROS.

## Ruta A — Documentación y portal

La más ligera. Solo necesitas Node.js 20.9 o superior.

```bash
git clone <url-de-este-repositorio>
cd anySLAM
npm install
npm run dev
```

Comandos disponibles:

| Comando | Qué hace |
| --- | --- |
| `npm run dev` | Levanta el portal en `http://localhost:3000` |
| `npm run build` | Compila y valida todas las páginas |
| `npm run gen:catalog` | Regenera el catálogo desde `data/repositories.yaml` |

## Ruta B — Entrenamiento por refuerzo

Requiere Ubuntu 22.04+, GPU NVIDIA y paciencia: la instalación completa lleva varias horas.

1. Instala los drivers NVIDIA y verifica con `nvidia-smi`.
2. Instala NVIDIA Omniverse y, desde su launcher, Isaac Sim 5.0.0.
3. Clona e instala Isaac Lab:

   ```bash
   git clone https://github.com/isaac-sim/IsaacLab.git
   cd IsaacLab
   ./isaaclab.sh --install
   ```

4. Clona `Anymal-Research` **fuera** del directorio de Isaac Lab e instala la extensión en modo
   editable:

   ```bash
   git clone https://github.com/jesusMBhuy/Anymal-Research.git
   cd Anymal-Research/anymal-d-managerbased/anymalDTraining
   /ruta/a/isaaclab.sh -p -m pip install -e source/anymalDTraining
   ```

5. Verifica:

   ```bash
   python scripts/list_envs.py
   ```

El procedimiento completo, con los detalles de configuración del activo USD, está en el README
de ese repositorio.
