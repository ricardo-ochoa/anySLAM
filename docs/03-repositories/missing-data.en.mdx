## How to close an item

1. Get the fact from the right source (code, the responsible person, or a measurement).
2. Edit the corresponding page under `docs/`, in both languages.
3. Strike the item off this list.
4. Open a Pull Request.

If a fact turns out to differ from what this documentation assumed, correct the assumption
**and** leave a note of what was previously believed. That record keeps the error from coming back.

## For repository maintainers

If you maintain a component, `templates/repo-intake.md` is a twelve-question form that closes
most of these items in one sitting.
