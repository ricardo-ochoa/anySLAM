## Cómo cerrar un punto

1. Consigue el dato de la fuente correcta (código, la persona responsable, o una medición).
2. Edita la página que corresponda en `docs/`, en los dos idiomas.
3. Tacha el punto de esta lista.
4. Abre un Pull Request.

Si un dato resulta ser distinto de lo que esta documentación supone, corrige la suposición
**y** deja escrito qué era lo que se creía. Ese registro evita que el error vuelva.
